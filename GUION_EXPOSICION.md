# Glovta · Guion de exposición de 30 minutos

Usá un mismo caso ficticio durante toda la exposición: una persona que busca su primer puesto digital. La pauta asigna 30 minutos a la exposición grupal, 20 a preguntas y 10 a deliberación. Asignen a cada integrante un tramo con una acción en vivo y una decisión técnica para explicar.

| Tiempo | Qué mostrar | Qué decir o hacer |
| --- | --- | --- |
| 0:00–4:00 | Portada y problema | Abrí con «¿Por dónde empieza alguien que quiere su primer trabajo digital?». Describí las decisiones que enfrenta: cómo presentar su perfil, qué oportunidades explorar y qué habilidad reforzar. |
| 4:00–7:00 | Propuesta de Glovta | Explicá cómo el perfil profesional, la búsqueda y la formación forman un recorrido. Presentá el caso ficticio y fijá un objetivo concreto para la demo. |
| 7:00–12:00 | Career Passport | Mostrá cómo completar el perfil de ejemplo. Explicá qué información aporta cada paso y usá el resultado visible para introducir la búsqueda. |
| 12:00–16:00 | Oportunidades | En el entorno de evaluación validado, la empresa publica el puesto del caso. Desde otra sesión, la persona lo busca y envía su presentación. La empresa pasa la solicitud a revisión. El candidato vuelve a ingresar y muestra el estado. Si la integración de evaluación sigue pendiente, usá la evidencia local e identificá el entorno ante el tribunal. |
| 16:00–20:00 | Formación | Abrí el catálogo demo y elegí un recurso de ejemplo. Relacioná el recurso con una habilidad concreta del perfil. Cerrá el caso explicando cuál sería el próximo paso de esa persona. |
| 20:00–24:00 | Arquitectura y datos | Distinguí la demo web con datos locales de la API Express. Explicá las responsabilidades de cada parte y qué evidencia haría falta para demostrar la integración con Supabase. |
| 24:00–28:00 | Pruebas y alcance | Explicá qué cubren las pruebas locales con dependencias simuladas. Para accesibilidad, mostrá una tarea que hayas ensayado con teclado y comentá qué observaste. Separá las funciones demostradas de las pendientes de validar. |
| 28:00–30:00 | Cierre | Volvé a la pregunta inicial. Cerrá con «El próximo paso es observar si una persona puede completar este recorrido y decidir cómo avanzar». Explicá qué medirías: tareas completadas y puntos donde se necesita ayuda. |

## Antes de exponer

- Cronometrá un ensayo completo. Tomá el minuto 20 como punto de control para terminar la demo a tiempo.
- Usá datos ficticios. Guardá capturas del perfil, la búsqueda y el catálogo para seguir explicando el caso si falla la conexión.
- Probá la versión que vas a mostrar con el tamaño del proyector. Si la mesa exige una APK o una demo integrada, verificá esos entregables antes de incorporarlos.
- Reservá 5 minutos del bloque de demo para ejecutar el recorrido en la APK instalada. Ensayá el relevo entre integrantes y el cambio de pantalla. El bloque queda pendiente hasta verificar la APK.
